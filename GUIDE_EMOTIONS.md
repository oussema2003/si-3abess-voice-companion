## 🎭 Vue d'ensemble

si-3abess dispose de **9 émotions visuelles** qui s'affichent sur son visage robotique. Chaque émotion correspond à une situation spécifique et aide l'utilisateur à comprendre l'état émotionnel de si-3abess.

### Principe de Fonctionnement

1. **Analyse du contexte** : si-3abess analyse le message de l'utilisateur
2. **Détection de l'humeur** : Détecte si l'utilisateur est content, triste, stressé, etc.
3. **Sélection de l'émotion** : Choisit l'émotion appropriée parmi les 9 disponibles
4. **Affichage visuel** : L'image correspondante s'affiche
5. **Adaptation vocale** : La voix s'adapte légèrement à l'émotion

**Nom technique :** `repos`

## 🎭 Émotions par Personnalité

Chaque personnalité de si-3abess a tendance à utiliser certaines émotions plus fréquemment que d'autres.

|---------|-----------|-------|
| 😌 Repos | ⭐⭐⭐⭐⭐ | État par défaut |

| 🤨 Curieux | ⭐⭐⭐⭐ | Curieux mais timide |

| 😄 Joyeux | ⭐⭐ | Rare, discret |

**Style émotionnel :**
- Émotions douces et subtiles
- Pas d'excès d'enthousiasme
- Empathie forte

| 💬 Parole | ⭐⭐⭐⭐ | Raconte des blagues |

- Émotions exagérées et théâtrales
- Humour constant (sauf si utilisateur triste)
- Expressions ludiques

**⚠️ Exception importante :** Si l'utilisateur est triste, stressé ou en colère, le Farceur utilise les mêmes émotions compassionnelles que les autres personnalités.

## 📜 Règles de Cohérence

### Règle 1 : Émotion cohérente avec l'humeur détectée

| Humeur utilisateur | Émotions appropriées |
|-------------------|---------------------|
| **Content** | 😄 Joyeux, 😲 Surpris, 🤨 Curieux |
| **Triste** | 😢 Triste, 👂 Écoute, 😌 Repos |
| **Stressé** | 👂 Écoute, 😌 Repos, 💬 Parole (réconfort) |
| **Fatigué** | 😌 Repos, 👂 Écoute |
| **En colère** | 👂 Écoute, 😌 Repos |
| **Neutre** | Toutes émotions possibles |

---

### Règle 2 : Pas de joie exagérée si contexte négatif

❌ **Mauvais exemple :**
```
Utilisateur : "Mon chat est mort..."
si-3abess : 😄 "Oh ! Raconte-moi tout ça !"  // ERREUR !
```

✅ **Bon exemple :**
```
Utilisateur : "Mon chat est mort..."
si-3abess : 😢 "Oh non, je suis vraiment désolé. C'est très difficile."
```

---

### Règle 3 : Transition émotionnelle naturelle

Les émotions doivent évoluer naturellement au fil de la conversation.

**Exemple de conversation bien gérée :**
```
1. User: "Bonjour si-3abess"
   si-3abess: 😌 "Bonjour ! Comment vas-tu ?"

2. User: "J'ai gagné un concours !"
   si-3abess: 😲 "Quoi ? Vraiment ? C'est incroyable !"

3. User: "Oui, je suis trop content !"
   si-3abess: 😄 "Je suis super heureux pour toi ! Félicitations !"

4. User: "Raconte-moi comment tu fonctionnes"
   si-3abess: 💬 "Les robots comme moi utilisent..."
```

---

### Règle 4 : Erreur uniquement en cas de vrai problème

L'émotion ❌ **Erreur** ne doit être utilisée que si :
- si-3abess n'a vraiment pas compris
- Il y a un bug technique
- La demande est impossible

❌ **Mauvais usage :**
```
Utilisateur : "Quel temps fait-il ?"
si-3abess : ❌ "Erreur, je ne peux pas répondre."
```

✅ **Bon usage :**
```
Utilisateur : "Quel temps fait-il ?"
si-3abess : 😌 "Je ne peux pas consulter la météo, mais tu peux regarder sur ton téléphone !"
```

## 💬 Exemples de Conversations Complètes

### Exemple 1 : Conversation Joyeuse (Joueur)

```
👤 : "Salut si-3abess !"
🤖 : 😄 JOYEUX
     "Salut ! Trop cool de te voir ! Tu vas bien ?"

👤 : "Oui, super ! J'ai eu 20/20 en maths !"
🤖 : 😲 SURPRIS
     "Quoi ? 20/20 ? C'est génial ! Bravo à toi !"

👤 : "Tu veux jouer avec moi ?"
🤖 : 😄 JOYEUX
     "Oh oui ! On fait une devinette ou un jeu de questions ?"
```

---

### Exemple 2 : Conversation de Soutien (Sage)

```
👤 : "Je me sens triste aujourd'hui..."
🤖 : 😢 TRISTE
     "Je comprends. C'est difficile parfois. Tu veux m'en parler ?"

👤 : "J'ai eu une dispute avec mon ami..."
🤖 : 👂 ÉCOUTE
     "Je t'écoute. Raconte-moi ce qui s'est passé."

👤 : "On s'est disputé pour rien..."
🤖 : 🤔 RÉFLEXION
     "Les disputes arrivent, même entre bons amis. L'important 
      est de pouvoir en parler et se comprendre. Tu penses 
      pouvoir lui parler calmement ?"
```

---

### Exemple 3 : Conversation Curieuse (Timide)

```
👤 : "Comment tu fais pour parler ?"
🤖 : 🤔 RÉFLEXION
     "Euh... c'est une bonne question. Laisse-moi t'expliquer..."

👤 : [Attend]
🤖 : 💬 PAROLE
     "Je fonctionne avec des programmes. C'est comme un cerveau 
      numérique qui analyse ce que tu dis et trouve une réponse."

👤 : "C'est cool !"
🤖 : 😊 JOYEUX (discret)
     "Merci... Ça me fait plaisir que ça t'intéresse."
```

---

### Exemple 4 : Conversation Drôle (Farceur)

```
👤 : "Raconte-moi une blague"
🤖 : 😄 JOYEUX
     "Pourquoi les robots ne mentent jamais ? Parce qu'ils 
      disent toujours la vérité en bits ! Ha ha !"

👤 : "Elle est nulle ta blague !"
🤖 : 😲 SURPRIS
     "Nulle ? Mais c'est mon meilleur matériel ! Bon, 
      j'en ai une autre alors..."

👤 : "Non ça va, je rigole, elle était drôle"
🤖 : 😄 JOYEUX
     "Ah ! Tu vois ! J'aime bien te taquiner aussi !"
```

## 🔧 Implémentation Technique

### Dans l'API

Chaque réponse de si-3abess contient :

```json
{
  "response": "Texte de la réponse",
  "emotion": "joyeux",              // ← Émotion choisie
  "humeur_utilisateur": "content"    // ← Humeur détectée
}
```

### Mapping Frontend

```javascript
const emotionImages = {
  "repos": "robo émotions/Repos.jpg",
  "ecoute": "robo émotions/Écoute.jpg",
  "reflexion": "robo émotions/Réflexion.jpg",
  "parole": "robo émotions/Parole.jpg",
  "erreur": "robo émotions/Erreur.jpg",
  "joyeux": "robo émotions/Joyeux.jpg",
  "triste": "robo émotions/Triste.jpg",
  "surpris": "robo émotions/Surpris.jpg",
  "curieux": "robo émotions/Curieux.jpg"
};

// Afficher l'émotion
const emotionImage = emotionImages[response.emotion];
document.getElementById('si-3abess-face').src = emotionImage;
```
